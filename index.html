Ao final da aula, o aluno deverá:

  • reconhecer algumas palavras básicas em inglês usadas na tecnologia;
  • conseguir se apresentar usando frases simples;
  • entender o conceito de algoritmo;

PARTE 3

O que é lógica?

"Se eu pedir para vocês ensinarem um robô a fazer um sanduíche, o que vocês diriam?"

Provavelmente: "Faça um sanduíche."

Então pergunte: "Mas o robô sabe o que é um sanduíche?"

Lógica é organizar ideias e passos para chegar a um resultado. Programadores usam lógica para dizer ao computador o que fazer e em qual ordem fazer.
4

O que é um algoritmo?

Algoritmo é uma sequência de passos para realizar uma tarefa ou resolver um problema.

Exemplo de algoritmo: escovar os dentes

  1. pegar a escova;
  2. colocar pasta de dente;
  3. molhar a escova;
  4. escovar os dentes;
  5. enxaguar a boca;
  6. lavar a escova;
  7. guardar a escova.

"E se eu colocar a pasta depois de escovar os dentes?" Eles perceberão que a ordem importa.

5

Desafio do robô humano

Essa pode ser a atividade principal da primeira aula.

Escolha um aluno para ser o robô. Outro aluno precisa dar instruções para o robô chegar até determinado ponto da sala. Por exemplo:

dê 3 passos para frente
vire para a direita
dê 2 passos
pare

O "robô" só pode fazer exatamente o que foi pedido. Se alguém falar "vá até a porta", o robô pode responder "Como?"

O computador não "adivinha". Ele precisa receber instruções claras.
6

Lógica do cotidiano

"Você quer sair de casa, mas está chovendo. O que você faz?"

SE estiver chovendo pegar o guarda-chuva SENÃO sair normalmente

SE = IF   |   SENÃO = ELSE

E pronto: eles já tiveram contato com uma das ideias fundamentais da programação.

Desafio rápido

"O que o programa deve fazer?"

SE a senha estiver correta entrar SENÃO mostrar "senha incorreta"

Se a senha for 1234 e a senha correta for 1234, o que acontece? → entrar.

E se a senha for 5678? → senha incorreta.

Desafio extra

"Quem consegue encontrar um erro no algoritmo abaixo?"

  1. colocar o tênis
  2. colocar a meia
  3. sair de casa

Resposta: a meia deveria ser colocada antes do tênis.

Programar também é encontrar e corrigir erros, e isso introduz naturalmente o conceito de bug.

Lógica bem curtinho

Em vez de um vídeo muito infantil sobre programação, uma explicação direta seguida de demonstração prática:

"Um algoritmo é uma sequência de passos para realizar uma tarefa."

Como fazer um sanduíche?

  1. pegar o pão
  2. abrir o pão
  3. colocar o recheio
  4. fechar o pão

"E se eu colocar o recheio depois de comer?" Os alunos entendem a ideia de ordem dos passos, base da lógica de programação.
